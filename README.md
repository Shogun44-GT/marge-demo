# Marge — démo

Démo publique de **Marge** : posez vos questions de gestion en français,
obtenez la réponse chiffrée en 10 secondes — sans tableur, sans comptable,
sans SQL.

Boutique fictive « Lueur & Cire » : 60 produits, 900 clients, 2 960 commandes.
Lecture seule : seules les requêtes SELECT sont autorisées.

Déployée gratuitement sur Streamlit Community Cloud. La clé `GROQ_API_KEY`
est fournie via les secrets du Cloud (jamais dans ce dépôt).
